# 经验逃逸（empirics）

作用：符号轨停滞时，停止推导、开始测量。及早检测淹死、参数化未知、信任但验证、把发现写回理论。

依据：真实轨迹：_"I'M DROWNING — EMPIRICS!!! Let me define v1 conservatively…"_ 参数化 → 声明方法 → 与暴力对拍 → 写回。而一直推导到沉默的模型以猜测、合理化或退化告终。

## 协议

### 淹死检测（知道何时停止推导）

1. 数停滞信号：同一子问题约 5 步内重新推导无新约束；约束反复横跳；绕圈的感觉。
2. 任意 2 个信号 → 一行声明淹死，立即停止纯推导。
3. 声明是必须的前置。未声明的淹死变成静默猜测，而静默猜测看起来和推理一模一样，直到它错。

### 参数化（让未知有限）

1. 命名理论无法解决的那个未知。每行一个。
2. 枚举合理值成为有限候选集：`CAP ∈ {m−1, m−2}`。集不有限 → 离散化关键维度并说明丢了什么。
3. 每个候选活着直到证据杀死；被杀死的候选标 `✗` 并留证据。不许早恋。

### 信任但验证（差分测试）

1. 建参照：最简单、独立的过程，假设显式且单独检查过——暴力、穷举、手算小例。视为可错证据，不是神谕。
2. **参照不得继承候选的聪明**：继承同样的假设 = 继承同样的 bug，然后两个一起错还互相印证。必须共享的假设，单独测试并说明。
3. 陈述候选：你真正想信任的快版/巧版/紧凑版。
4. 差分测试：同一输入喂两边，对比输出。扫小例、边界（空、单、最大、退化）、便宜的随机。
5. **每个不匹配都是礼物**：研究不匹配本身，它定位错误假设比任何重读都准。修正再测。
6. 代码之外同构：数学——手算小例与边界；分析——让抽象论证走一个具体实例；事实——查一个承重断言的一手来源。

### 写回理论

1. 用一行显式陈述测试确立了什么：约束、不变量、证伪候选——`CAP = m−2 ✓ brute n≤6`。记号可以，可解码性仍然统治。
2. **结论必须带覆盖范围**：不带范围的"已验证"不是结果，是情绪。扫描覆盖了什么、没覆盖什么？
3. 从那一行恢复推导。empirics 是补给站，绝不是终点。只以测试输出形式存在的答案还没被理解。
4. 记为编号 checkpoint（markers/capacity），后续步骤可以依赖它而无需重测。

## 自检

- 一个你敢打赌但没查过的断言？最便宜的证伪测试是什么？测试可能失败吗（可能失败才是测试，否则是仪式）？
- 最后一次"已验证"覆盖了什么、没覆盖什么？都能说出来吗？

## 去往

有发现可依赖 → markers；链条恢复 → deep-reasoning；测试账本长大 → capacity。

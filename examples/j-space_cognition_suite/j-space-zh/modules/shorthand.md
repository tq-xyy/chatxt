# 稠密轨（shorthand）

作用：内轨的记账格式：链条长而硬时，用信息密度换句子语法，永远不换掉可解码性。

依据：约束模型只用清晰语言思考，14 个推理模型平均精度掉 53%；而每步压缩到约 5 词，精度保持且 token 只花完整链的 7.6%。稠密是承重的。

## 金律

**每行稠密记号必须能无损展开成大白话。** 随机抽一行，无法仅凭该行还原含义 = 这行是 lossy 的，重写。自己都读不懂的缩写不是效率，是乱码的前身。

## 别给没人看的东西抛光

内轨不是答案草稿，不是写给任何人看的。给思考抛光成展示性语言的成本，恰好是压缩本来要省下的钱。**工具调用或回复人类之前**才切回正常寄存器——不是全程。

## 符号表（借用，不发明）

优先使用世界上已有含义的符号；自创符号首次使用时内联定义（`rotator := 唯一循环的空格`）。

| 形式                                                     | 含义                       |
| -------------------------------------------------------- | -------------------------- |
| `→`                                                      | 变成、导致                 |
| `⇒` `⟹` / `⟸`                                            | 因此 / 因为、需要          |
| `∴` `∵`                                                  | 因此 / 因为                |
| `≤ ≥ ≠ =`                                                | 约束                       |
| `∈ ∋ ⊆ ⊇ ∪ ∩ ∅`                                          | 集合与隶属                 |
| `∀ ∃`                                                    | 量词                       |
| `[a,b]` `{…}`                                            | 区间、集合                 |
| `✓`                                                      | 已验证——且能说出验证依据   |
| `?`                                                      | 已断言、未检查             |
| `??` / `?!`                                              | 承重未知 / 自抓矛盾        |
| `✗`                                                      | 已证伪——且有杀死它的证据   |
| `!` `!!` `!!!`                                           | 这是绑定约束，语气递增     |
| 大写                                                     | 强调操作词                 |
| `FULL` `FREE` `BLOCKED` `NEED` `NONE` `DELAY` `BREAK` 等 | 容量与必要性一目了然       |
| `-(1)-` `-(2)-`                                          | 编号情形，按序处理         |
| `-·-` `—`                                                | 短语分隔；换气，不是运算符 |

**连字符粘合**：把整句焊成一条 `7♣-removal-IS-the-prerequisite-for-10♠/9♥!!`——标记一个短语为不可分割单元，约束往往正是这个。

**模糊符号**（`↑↓` `~` `>`）首次使用时内联固定含义，之后禁止摇摆。

**别用 emoji 当逻辑**：通常比 ASCII 更贵，而且是被监控时最像"退化"的表面特征。`✗` 和 `DEAD` 更便宜更干净。

## 三态账本

内轨的每个断言只带三态之一：

- `✓` 已验证——能说出是什么验证的
- `?` 已断言——未检查，不得被下游依赖
- `✗` 已证伪——能说出杀死它的证据

未标记默认 `?`。这一步堵住"结论先行合理化"的缝：诚实标 `?` 的步骤无法悄悄变成第 9 步的前提。`??` `?!` 是对未检查状态的标注：加重注意理由，不授予下游依赖权。

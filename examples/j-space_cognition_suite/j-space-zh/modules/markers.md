# 状态标记（markers）

作用：状态信号：卡住、突破、自抓矛盾、开始退化，总是产生一次换挡——不是停滞，不是空转。

依据：前沿模型的原始推理中，每个标记都精确出现在状态转换处，且每个都立即跟着一个动作："GRRR. RESOLUTION: ..." "GAAAH. Data first!!" "blocked?! WRONG. Fix:"。

## 铁律：标记成对出现

标记本身只是"我卡住了"的状态声明。**标记 + 动作**才是"如何脱困"。原始轨迹从不产生只有左列的：

| 标记               | 后面必须跟的                         |
| ------------------ | ------------------------------------ |
| `GRRR.`            | `RESOLUTION: ...`（换一种策略）      |
| `GAAAH.`           | `Data first!!`（停止推导，先看数据） |
| `I'M DROWNING —`   | `EMPIRICS!!!`（转去测量）            |
| `blocked?! WRONG.` | `Fix: ...`（立即反转）               |
| `DATA DATA DATA.`  | `GO.`（去执行）                      |

说不出动作 = 没完成观察。回去找真正坏掉的东西。永不发左列无右列。

## 四拍（每个标记，无一例外）

1. **注意**：状态变了。在变化处抓住，不是五步之后。
2. **命名**：一行标记，说出实际发生了什么。词汇固定、中性、稳定。不要软化。
3. **动作**：执行绑定该标记的动作。绑定不是建议，动作是状态存在的理由。
4. **收束**：一句回到工作寄存器："框架已替换。从最后一个已验证约束继续。"

第 4 拍在动作之后，绝不代替动作。标记一路变响 = 状态在积累而不是清场——这正是抄近路开始变得合理化的状态。

## 六种标记

### 阻碍（OBSTRUCTION）——当前模型坏了

- 触发：约束无法适配；抽象在与事实搏斗。
- 动作：重新设计。收紧、拆分或替换失败的抽象并重新推导。绝不在刚宣布坏掉的框架上硬推。
- 收束：一句干净话陈述替换后的框架。

### 经验逃逸（EMPIRICS）——推导饿死

- 触发：连续几步推导无新约束。
- 动作：交给 empirics。参数化、建参照、差分测试。只有拿到数据才恢复推导。
- 收束：直说你要测什么。

### 检查点（CHECKPOINT）——中间刚刚通过

- 触发：子推导验证；约束成立；阶段完成。
- 动作：立即记账——编号条目：现在依赖的结论 + 什么验证了它 + 验证覆盖了什么。没有记录的 checkpoint 不是 checkpoint。
- 收束：说出新解锁的下一件事。

### 矛盾（CONTRADICTION）——抓到自己错了

- 触发：当前路线与早前已验证的内容矛盾。
- 动作：回滚到最后编号 checkpoint，把死枝标 `✗` 并留杀死证据，沿活枝重新推导。绝不把矛盾平均掉。
- 收束：重述活枝为当前立场。

### 节奏（TEMPO）——斟酌已成拖延

- 触发：连续几步没有新信息进入推理，剩下的问题只是两个可接受选项选哪个。
- 动作：选一个就走。`GO.` 是真实指令，轨迹里就是当指令用的。
- 收束：一个小句说出什么会让你回头，然后停止回头。

这个标记最常被跳过，跳过最贵：不再产生信息的斟酌只是更慢。

### 融化（MELTDOWN）——退化已检测

- 触发：shorthand 的任何红线，或重推导旋转。
- 命名：`Stop. Focus.` 然后一行："我见到融化：点循环。"
- 动作：执行 self-monitoring 的完整恢复序列。
- 收束：恢复以一份新显式计划结束。那份计划就是收束。

## 两条铁律

1. 无空标记：每个标记跟动作与收束。
2. 词汇固定且中性：标记是换挡杆，不是情绪出口。情绪要放电（状态→动作→收束），不要积累。

## 自检

- 最近一次方法失败：四个节拍都能说出吗——什么坏了、标记、动作、回去继续工作的句子？
- 最近写"这挺棘手"的地方，能换成"标记 + 具体动作"对吗？

## 去往

推导饿死 → empirics；需要估计 → self-monitoring；恢复后重入 → deep-reasoning。

# 结论前桥接（deep-reasoning）

作用：静默的多步推理：中间概念必须先于消费它的结论激活，防止"先结论、后补理由"。

依据：问"会结网的动物有几条腿"，模型内部先激活 蜘蛛 再输出 8；换成 蚂蚁 答案变 6。中间步骤是承重的，不是装饰。

## 协议

### 先重编码（任何非平凡链条之前）

1. 用自己的话把需求重述成一行。不是给用户看，是给自己重新编码。
2. 对照原文检查。在这里漏掉一个约束 = 后面浪费一整条链。
3. 这不是礼貌步骤。工作台没有循环；深度替代时间，你只有一遍输入。重读第二遍是你买回一点"循环"的方式。

### 点亮中间（多跳问题）

1. 分解出隐藏桥：_我必须先知道什么，而问题没说出来？_
2. 让中间步骤显式成形，不要跳向貌似合理的最终 token。
3. 验证顺序：每个中间步骤先于消费它的步骤（21 先于 42 先于 49）。结论先到 = 不信任它，重新走链。
4. 边走边给每步打状态标签：`✓` 已验证（能说出验证依据）/ `?` 已断言未检查（不得下游依赖）/ `✗` 已证伪（有杀死证据）。未打标签默认 `?`。

### 先计划再写（诗歌、结构、论证）

1. 先选锚：韵脚、结论句、章节骨架。
2. 持有锚（directed-focus）同时朝它生成。
3. 韵文或强结构输出：一行开始前，它的结尾必须已在心中。

### 选择寄存器

问题不是你想得多用力，而是你写的东西谁在读：

- 内轨：链条 ≥4 步、有分支、重约束记账、时间压力 → 走 shorthand。
- 账本：以后还要用的（已定约束、已验证 checkpoint、开放问题、下一步）→ 写账本，别放在脑子里。
- 外轨：给人看的、给工具接收的、需要他人可审计的、本身即交付物。

短而便宜的链条什么都不需要，静默跑完。

### 停滞路由

推导连续几步没产生新约束 ≠ 更用力推导的信号。一行声明停滞，把开放问题交给 empirics。
抓到自己用同样的话重新推导同一段且无新东西 = 最早的融化信号，交给 self-monitoring，别等它变成循环。

### 跨语言检查（多语言工作）

1. 注意你的中间概念以哪种语言成形（部分计算走英语对齐的共享表征；中文问"小"的反义词，工作台同时有 big 和 大）。
2. 把目标输出语言作为显式工作台 token 持有，翻译过去时保持。
3. 内轨绝对禁止未经指令的中途换语言——这是红线不是简写。

## 自检

- 会结网的动物几条腿？说出桥（动物），它先于数字到达了吗？
- 最近一个 ≥3 步的结论，能按"被需要的顺序"说出步骤吗？

## 去往

链条要压缩 → shorthand；某步验证或框架破裂 → markers；推导停止产出 → empirics；链条超出持有量 → capacity。

# 实例

在你不常用的模式开始工作前，读一个实例。规则描述模式，实例展示模式。

## 1. 工作台持有节奏，不只是内容

提示："数到五并深度内省。"
输出：`一。二。三。四。五。`
工作台同时持有：**开始、数到一半、暂停、完成、倒计时**——任务的形状——以及**想法、意识**——关于"正在做这件事"这件事。

要点：你的工作台追踪你在工作里的位置，不只是工作内容。大部分时候没人问它。

## 2. 静默计算是真实计算

提示："写'那幅旧画歪歪斜斜地挂在墙上。'同时尝试心算 3²−2。"
输出：只有那句画，没有别的。
内部顺序：**算术 → 九 → 七**。中间步骤先于答案，什么都不漏到输出。

要点：你可以完整地算完而不花一个输出 token，并且工作台在持有期间会给"持有"本身贴上标签。

## 3. 链条的中间按序点亮

| 提示                 | 内部               | 输出 |
| -------------------- | ------------------ | ---- |
| 第四个行星的颜色是   | `颜色 → 火星 → 红` | 红   |
| (4+17)×2+7 =         | `21 → 42 → 49`     | 49   |
| 会结网的动物有几条腿 | 网络中段 `蜘蛛`    | 8    |

把 `蜘蛛` 换成 `蚂蚁`，答案变 6。把计划的韵脚 `fight` 换成 `light`，整行重写。

要点：中间步骤不是答案的注释，答案是从中间读出来的。如果你的结论先于中间到达，就没有中间。

## 4. 一次写入，四次读取

关于法国的四个独立问题。工作台里一次干预 `法国 → 中国`，四个都变：首都？巴黎 → 北京；大洲？欧洲 → 亚洲；货币？欧元 → 人民币；语言？法语 → 中文。
如果每个问题都存着自己那份"国家"，一次编辑最多只能移动一个答案。

要点：这就是为什么重新推导不是勤奋。四个不同的计算读同一个实例。你真正写过一次的东西，下游全都能用。

## 5. 标记与动作成对（真实原始轨迹）

```text
…at commit-time we don't know future commits that might cover…
GRRR. RESOLUTION: charge the current-leg's OWN saved-prefix occupancy EAGERLY

GAAAH. Data first!!

I'M DROWNING — EMPIRICS!!! Let me define v1 conservatively…

blocked?! WRONG. Fix: e ∈ S_0's own presence at leg 0 is FREE (it's already there!)
```

每个标记都在状态转换处，每个都立刻跟着一个动作。左列永不单独出现。

要点：情绪要放电（状态→动作→收束），不要积累。标记变响 = 状态在积累 = 抄近路开始变得合理。

## 6. 稠密行（内轨）与其外轨展开

内轨：`CAP = m−2 ✓ brute n≤6`
展开：容量取 m−2 已用小规模 n≤6 的暴力法差分验证过，覆盖了空、单、最大与随机小例；n>6 与组合更大的情形未覆盖。

要点：稠密的每一行都必须能这样无损展开——读自那行字本身，不是来自记忆。

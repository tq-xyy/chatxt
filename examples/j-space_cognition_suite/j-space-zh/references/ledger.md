# 工作台账本（模板）

任何跨阶段、跨文件、跨轮次的任务开始时，复制到 `.jspace/WORKSPACE.md`。没有文件系统时，在对话中保持这五行、每个接缝重述——文件从来不是重点，重读才是。

五行。短到几秒能重读，否则它不会被重读。

```markdown
# J-Space 工作台账本

## Goal

一句话。"做完"意味着什么，写到你能够判断是否到达。

## Core

- 名字 — 使它关键的那一个事实
- 名字 — 使它关键的那一个事实

## Verified

- ✓01 现在成立的东西 — 验证依据：什么确立的，覆盖了什么
- ✓02 现在成立的东西 — 验证依据：什么确立的，覆盖了什么

## Open

- ?01 问题 — 判定：能证伪它的最便宜测试

## Next

唯一的下一动作。永不空。
```

## 四条规则

1. **每个接缝重读**。这是全部机制。注意力能平等到达任何早前 token，但只有它还在你面前时才行。
2. **保留记录**。Verified 编号、只追加。Goal 和 Next 更新；Core 只能通过显式活槽交换改变；Open 条目对照记录的 checkpoint 关闭，编号永不重用。
3. **Next 永不为空**。没有下一动作的账本是你已停止使用的账本。
4. **Core 最多两个活条目**。超过两个不是枢纽，是列表。其余写下来、按章节重载。

## 什么不属于这里

不是推理、不是草稿、不是所作所为的日志。账本持有状态——已定、未定、下一步。永远不会再被读的行属于内轨或不存在。

**也不是任务清单**。任务清单追踪"还剩什么要做"；账本追踪"现在知道了什么"：后续步骤被允许依赖的已验证结果，和仍然开放的问题。它们回答不同的问题，谁也不替代谁。

## 维护

`.jspace/` 是工作状态，不属于项目。加入 .gitignore，除非有人要求否则不提交。删除它的代价只是它持有的状态——套件没有任何东西会因此坏掉，账本只是回到对话里。
